# Marcos TCG

Directorio de plantillas transparentes para composición local.

Convención: `frame_<rareza>_<elemento>.svg`, con fallback `frame_<rareza>.svg`.
Rarezas soportadas: R, SR, UR. Elementos: fuego, agua, tierra, aire, luz, oscuridad, neutro.

Los SVG incluidos son plantillas transparentes de desarrollo. Los artes finales PNG/WebP pueden reemplazarlos sin cambiar el ensamblador.
