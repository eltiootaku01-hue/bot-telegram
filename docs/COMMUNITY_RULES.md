# Reglas operativas — Café Otaku

Estas reglas describen el comportamiento operativo mínimo de la comunidad.

1. Respeto entre integrantes: no se permiten acoso, amenazas ni ataques personales.
2. No spam, flood ni mensajes diseñados para molestar deliberadamente.
3. No compartir datos personales de terceros sin permiso.
4. Usar cada tema del foro para su propósito y evitar desvíos constantes.
5. Juegos, puntos y pedidos deben utilizarse de forma honesta; los errores no deben explotarse.
6. Seguir las indicaciones de moderación y coordinación.
7. Material ilegal o contenido que infrinja las reglas de Telegram no pertenece a la comunidad.

Estas reglas pueden ampliarse cuando se definan nuevas normas de convivencia.
