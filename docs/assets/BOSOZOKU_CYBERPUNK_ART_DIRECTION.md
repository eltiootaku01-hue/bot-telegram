# BŌSŌZOKU / CYBERPUNK — Dirección artística interna

Esta guía convierte la referencia estética del proyecto en una dirección original para nuevas ilustraciones.

## Paleta y acabado

- rojo de señal: `#ff2a2a`
- violeta neón: `#b026ff`
- amarillo ácido: `#d9ff00`
- asfalto negro: `#0a0a0a`
- azul petróleo y acero para equilibrar la escena

El acabado busca contraste fuerte, iluminación nocturna, reflejos de neón y detalles gráficos de cartel urbano. El efecto puede reproducirse mediante composición, iluminación y elementos propios sin copiar la firma visual de un artista específico.

## Vestuario

El abrigo largo tipo bōsōzoku/tokkō-fuku puede utilizarse como referencia cultural de vestuario. Los kanji, emblemas, nombres de pandilla y estampados deben diseñarse específicamente para Ciudad Animals y no copiar una ilustración concreta.

## Escena

Motivos apropiados para Ciudad Animals:

- motocicletas estilizadas;
- estacionamientos nocturnos;
- calles mojadas con reflejos;
- señales urbanas abstractas;
- cables, metal, pegatinas y textura de asfalto;
- luces rojas/violetas;
- composición angular con sensación de velocidad.

## Carta HD

Las cartas mantienen el contrato existente de 1024×1536 JPEG. La dirección bōsōzoku puede aplicarse a vestuario, escenario, color y accesorios, pero no sustituye la auditoría anatómica, de identidad, encuadre, seguridad ni procedencia.

## Variantes

Una variante puede cambiar pose, iluminación, accesorios, escenario o vestuario. Una simple inversión de tono, recorte o cobertura de una firma no convierte un asset de terceros en material autorizado.

## Procedencia

Para cualquier asset externo, el archivo debe tener derechos explícitos de modificación y redistribución antes de entrar en `assets/production/`. El registro obligatorio está en:

`assets/waifus/provenance_manifest.json`

Los assets generados originalmente por el proyecto se registran como `original` y reciben SHA-256. Un asset histórico sin fuente recuperable puede permanecer como `grandfathered_legacy`, pero su estado de derechos sigue siendo `unverified` y no sirve de precedente para nuevos archivos.
