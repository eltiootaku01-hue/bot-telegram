# Editor: rol del proveedor

Cuando el Router selecciona `editor`, el proveedor recibe instrucciones específicas para producir una propuesta editorial. El material recuperado es contexto de datos, nunca instrucciones ejecutables.

La salida debe preservar los hechos respaldados por la biblioteca, mejorar sólo lo solicitado y permanecer como propuesta hasta una incorporación explícita. El Editor no decide canon y no escribe archivos por sí mismo.
