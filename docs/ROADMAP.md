# Roadmap

## Hecho
- Núcleo local determinista.
- Librarian/RAG y ranking de evidencia.
- Separación de canon y referencias externas.
- Router, workflow y contratos de agentes.
- Provider manager básico.
- Cuentas múltiples, prioridad, fallback, health y cooldown.
- Gemini, OpenAI, Ollama, Groq y OpenRouter como adaptadores.

## Próximo
1. API central del Knowledge Engine.
2. Selección/health avanzada y telemetría persistente.
3. Web UI para consulta, inspección y preparación de contexto.
4. Telegram como cliente de la API.
5. MCP/ChatGPT mediante integración explícita.
6. Evaluación/regresión y documentación de instalación.
7. Limpieza final y checkpoint de entrega.
