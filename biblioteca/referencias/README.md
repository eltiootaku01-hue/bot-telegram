# Referencias externas

Esta carpeta contiene material de referencia sobre las obras originales que sirven de guía para las novelas de BOT-IA.

## Regla de autoridad

El contenido de esta carpeta NO es canon de una novela del usuario por defecto.

- `one_punch_man/` → referencia para **One Neko Punch**.
- `sword_art_online/` → referencia para **Neko Fish Online**.
- `highschool_of_the_dead/` → referencia para **Neko of the Dead**.
- `my_hero_academia/` → referencia para **My Neko Academia**.
- `attack_on_titan/` → referencia para **Attack on Neko**.

Las fuentes externas deben conservar su procedencia y, cuando sea posible, URL, fecha de consulta y alcance de la información.

## Política de actualización

BOT-IA puede incorporar información obtenida mediante investigación web autorizada por el usuario, pero debe almacenarla como **referencia externa**, nunca como canon propio.

Una afirmación no debe elevarse a hecho establecido sólo porque aparezca en una wiki. Si existen conflictos entre fuentes, BOT-IA debe conservar el conflicto y señalarlo.
