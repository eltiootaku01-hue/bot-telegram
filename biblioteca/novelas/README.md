# Perfiles de novelas

BOT-IA debe tratar cada novela como un proyecto independiente.

| Novela | Canon principal | Obra de referencia |
|---|---|---|
| One Neko Punch | `one_neko_punch` | One-Punch Man |
| Neko Fish Online | `neko_fish_online` | Sword Art Online |
| Neko of the Dead | `neko_of_the_dead` | Highschool of the Dead |
| My Neko Academia | `my_neko_academia` | My Hero Academia |
| Attack on Neko | `attack_on_neko` | Attack on Titan |

## Regla de separación

La columna **Canon principal** contiene los hechos de la historia del usuario.
La columna **Obra de referencia** sólo sirve para consultar reglas, ambientación,
personajes o conceptos de la obra original cuando el usuario lo permita o cuando
se necesite como guía narrativa. La referencia nunca se convierte automáticamente
en canon de la novela del usuario.

## Regla de Kuro

Cada novela puede tener una versión independiente de Kuro. No se deben trasladar
automáticamente poderes, recuerdos, relaciones, acontecimientos o conocimientos
de una novela a otra. Un crossover debe ser solicitado explícitamente.
